# 📚 Catálogo de Libros - LiterAlura

Este proyecto fue desarrollado como parte del desafío de **Alura Latam** en el programa ONE (Oracle Next Education).  
El objetivo es construir un catálogo de libros utilizando la **API de Gutendex**, manipular datos en **JSON**, almacenarlos en una base de datos y mostrar resultados a través de un menú interactivo en consola.

---

## ✨ Funcionalidades

✅ Conexión a la **API Gutendex** para obtener información de libros.  
✅ Procesamiento de datos en formato **JSON** con la librería Gson.  
✅ Almacenamiento y consulta en una base de datos.  
✅ Búsqueda de libros por título o autor.  
✅ Listado de libros registrados en el catálogo.  
✅ Interfaz en **consola** amigable y fácil de usar.

---

## 🛠️ Tecnologías Utilizadas

- **Java**  
- **Gson** (para parseo JSON)  
- **Gutendex API** (fuente de datos)
